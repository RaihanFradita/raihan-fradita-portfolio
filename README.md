# Raihan Fradita | AI Engineer Portfolio

Personal portfolio highlighting independent work in AI reliability, LLM applications, and financial intelligence.

## Featured projects

### [Waguri Framework](https://github.com/RaihanFradita/waguri-framework)

An experimental Python framework for inspecting LLM responses against supplied evidence. Its current evidence check uses normalized exact-text matching and returns structured results for review; it does not provide semantic fact verification or guarantee hallucination-free responses.

**Stack:** Python, Pydantic, pytest
**Status:** Under development

### [AIRA Business](https://github.com/RaihanFradita/AIRA-AI-Business)

A financial intelligence application with business dashboards, Excel/CSV imports, and AI-assisted analysis. Local Ollama/Gemma 3 4B is an optional AI provider alongside Anthropic and built-in analysis.

**Stack:** React, Vite, Bun, Elysia.js, PostgreSQL, Ollama
**Status:** Built — under audit and refinement

## Portfolio stack

- Next.js and React
- TypeScript
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```

Run the production build and lint checks with:

```bash
npm run build
npm run lint
```

The canonical site URL defaults to `https://raihan-fradita-portfolio.vercel.app` and can be overridden with `NEXT_PUBLIC_SITE_URL`.
