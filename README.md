## Engineering Principles

- **Build with purpose.** Solve a defined problem rather than adding AI for its own sake.
- **Evaluate, don't assume.** Use appropriate metrics and experiments to assess performance.
- **Keep systems understandable.** Prefer maintainable code and clear documentation.
- **Design for reliability.** Consider failure cases, data quality, security, and user experience.
- **Learn in public.** Document experiments, share implementations, and improve through feedback.
